# 镜头切片 3.4：技术架构与处理流程（Mac）

## 运行环境

- **系统**：macOS；建议 Python 3.11/3.12（最低 Python 3.10）。
- **界面**：PySide6 6.11.3（Qt Widgets / Multimedia）。
- **镜头分析与导出**：本机 FFmpeg / FFprobe + NumPy + Pillow。
- **AI 模型**：不需要下载任何大语言模型、视觉模型或模型权重。程序使用本地逐帧画面变化算法，而非在线 AI 服务。
- **数据安全**：视频在 Mac 本地处理，不上传服务端；任务历史和运行日志保存在用户目录。

## 核心文件

| 文件 | 作用 |
| --- | --- |
| `app.py` | 主窗口、中文界面、导入/处理队列、播放器、手动截图与持久化设置 |
| `scene_engine.py` | 视频帧解码、切换检测、代表帧选择、JPG 导出、历史结果及排除/恢复 |
| `shot_wall.py` | 镜头墙、网格预览及选中图大图浏览 |
| `crashlog.py` | Python 崩溃与退出日志 |
| `assets/ink_figure_hd.png` | 左下角固定小人物线稿（界面装饰，不加载模型） |
| `requirements.txt` | Python 依赖，固定 PySide6 版本 |
| `install_macos.command` | 创建虚拟环境、安装 FFmpeg 与 Python 依赖 |
| `launch_macos.command` | 启动本地程序并保留日志 |
| `build_macos.command` | PyInstaller 在 Mac 上生成 `.app` |
| `tests/` | 核心引擎与界面结构测试 |

## 工作流

1. 首次启动选择**统一输出目录**，系统会记住设置。
2. 拖入 MP4、MOV、MKV、AVI 等格式视频，建立待处理任务队列。
3. 通过“截图灵敏度”设置检测强度，点击绿色“开始解析”。
4. 本地按视频帧进行 RGB 差异、结构变化等分析，筛选候选切镜点，过滤部分闪光/运动误判。
5. 为每段镜头选代表画面并提取原尺寸高质量 JPG，同时保留片头画面。
6. 处理完成后在右侧预览截图；镜头墙可以集中浏览，播放器下方“截取当前画面”用于补帧。
7. 新视频导入时自动清理**已完成队列项**，但历史结果仍可查看，不删除已有 JPG；重复导入已完成视频允许重新解析，并输出到独立目录。

## 注意事项

- “100% 灵敏度”不等于 100% 镜头检出率；渐隐、叠化和相似运动可能仍需人工补帧。
- `requirements.txt` 的 PySide6 固定版本是 6.11.3，用于回避此前报告的退出析构问题；不保证在全部 macOS 环境中彻底无崩溃。
- `.app` 由源码打包产生，不包含 FFmpeg 可执行文件；运行 Mac 需另外安装 `brew install ffmpeg`。
- 此项目不包含模型权重，也不上传任何真实视频或生成的 JPG。

## Mac 应用图标

`assets/app_icon.png` 为窗口及运行时图标，`assets/app_icon.icns` 为 Finder、Dock 显示的打包图标。两个文件都由用户指定的原始 PNG 生成，未进行重新绘制。`build_macos.command` 和 GitHub Actions 的 PyInstaller 命令均显式传入 `--icon assets/app_icon.icns`，因此本机打包与云端构建显示一致。


## macOS Bundle Identifier 与图标构建规则

应用显示名称可以是「镜头切片」，但 PyInstaller 命令必须包含 `--osx-bundle-identifier com.scenecutter.app`，打包后检查 `CFBundleIdentifier` 并 ad-hoc 签名验证。应用图标来自 `assets/app_icon.png`，通过 `generate_macos_icon.command` 在 macOS 上生成 `assets/app_icon.icns`；避免源码仓库保留老版本 ICNS 导致图标未更新。
